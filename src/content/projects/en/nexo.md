# NEXO: Personal Reconstruction Engine

NEXO (formerly Mi Luz Interior) is a gamified personal development platform designed as a scalable Single Page Application (SPA). It provides a clear, measurable, and sustainable system for individuals seeking personal reconstruction through daily structure and visible progress.

## // TECHNICAL ARCHITECTURE

- **Modern Frontend:** Built with React 19 and Vite for extremely fast Developer Experience (DX) and optimized builds. UI styling is strictly maintained with Tailwind CSS.
- **Robust Backend:** Powered entirely by Supabase. It leverages PostgreSQL with Row Level Security (RLS) ensuring that "the frontend is insecure, the database protects itself."
- **Real-time Capabilities:** Uses Supabase Realtime for instant data sync and OAuth for secure authentication.

## [ STRATEGY_PHILOSOPHY ]
- **Action > Emotion:** The system prioritizes daily actions over fleeting motivation.
- **Visible Progress:** Everything is measurable. If progress is invisible, abandonment is inevitable. 
- **Gamification with Intent:** Designed strictly for sustainable discipline, focusing on Mental, Physical, and Professional domains.
