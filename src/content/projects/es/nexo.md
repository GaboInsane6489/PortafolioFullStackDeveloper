# NEXO: Motor de Reconstrucción Personal

NEXO (anteriormente Mi Luz Interior) es una plataforma de desarrollo personal gamificada. Diseñada como una Single Page Application (SPA) escalable, no es autoayuda tradicional; es un sistema estructurado, medible y sostenible diseñado para la reconstrucción a través de la disciplina diaria.

## // ARQUITECTURA TÉCNICA ESTELAR

- **Frontend Moderno:** Construido con React 19 y Vite para *builds* optimizados y una experiencia de desarrollo (DX) ultrarrápida. Los estilos se mantienen con Tailwind CSS.
- **Backend / Infraestructura:** Impulsado por Supabase (PostgreSQL). Implementa *Row Level Security* (RLS) bajo la regla de oro: "El frontend es inseguro. La base de datos se protege a sí misma."
- **Arquitectura Escalable:** Gestión de autenticación con OAuth, base de datos relacional y suscripción a datos en tiempo real (*Realtime*).

## [ STRATEGY_PHILOSOPHY ]
- **Acción > Emoción:** No importa cómo te sientes, importa lo que hiciste hoy.
- **Progreso Visible:** Todo debe ser medible. Si no se ve, no se sostiene.
- **Gamificación con Intención:** Organizado en dominios clave funcionales (Mentalidad, Cuerpo, Imagen Personal y Disciplina).
